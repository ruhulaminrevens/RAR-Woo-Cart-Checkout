WooCommerce cart and checkout UX toolkit with Bangladesh address fields and an optional Express Buy Now checkout modal.

== Features ==
* Bangladesh-only billing workflow.
* Searchable district-aware Town / City selector.
* Cart shipping calculator integration.
* Configurable Additional Information / Order notes.
* Admin-editable field labels and headings.
* Optional Express Buy Now modal.
* Editable Buy Now CSS selector.
* Safe fallback for unsupported product types.
* HPOS compatible.
* Classic Cart/Checkout support.

== Migration ==
Activate the plugin first, then deactivate the old WPCode snippets and test Cart, Checkout, Buy Now and Place Order before deleting the snippets.

== Important ==
Version 1.0.0 targets WooCommerce Classic Cart/Checkout templates. Cart/Checkout Blocks are not declared compatible.
