Bangladesh-first cart & checkout: smart address, BD phone validation, Express Buy Now, incomplete-order recovery, fraud protection and dashboard.

== Description ==

* Dashboard with orders, Express share, recovery rate, blocked attempts, 14-day chart and one-click health fixes.
* Bangladesh address workflow: District → searchable Town/City (64 districts, 630+ areas incl. metro thanas), optional email, Bangla label preset.
* Bangladeshi mobile validation (Bangla digits, +880, spaces) with live operator hint and clean storage.
* Express Buy Now modal with background add-to-cart, variations, "buy only this", gateway-safe redirects and mobile sheet.
* Checkout quantity editor, free-delivery progress bar with automatic free-rate selection, custom Place Order text and trust line.
* Incomplete-order capture and recovery list with Call/WhatsApp, statuses, notes, CSV export and one-click order creation.
* Customer Insight (success rate, history, block/unblock) on orders, customer score column, blocklist, cooldown, min order, COD limits.
* REST API for staff apps; HPOS compatible; translation-ready.

== Installation ==

1. Plugins → Add New → Upload Plugin → choose the ZIP → Install → Activate.
2. Open RAR Checkout → Dashboard and follow the Health check.
3. Deactivate old WPCode checkout / Buy Now snippets.

== Frequently Asked Questions ==

= Does it work with Checkout Blocks? =
It targets the Classic cart/checkout. The dashboard can switch the pages to Classic in one click and restore them later.

= Will uninstalling delete my data? =
No, unless "Delete all plugin data on uninstall" is enabled under Advanced. Orders are never touched.
