# Changelog

## v1.0.0 — 2026-09-23

Initial stable release.

### Added
- Consolidated Bangladesh checkout/address UX into a standalone WooCommerce plugin.
- Bangladesh-only country handling.
- Configurable billing-field labels and priorities.
- Optional removal of last name, company, address line 2 and postcode.
- District-aware searchable Town/City selection for Checkout.
- Town/City support in the Cart shipping calculator.
- Optional Ship-to-different-address hiding.
- Configurable Additional Information / Order Notes visibility.
- Consolidated Express Buy Now modal into the plugin.
- Admin-editable Buy Now selector, modal text, checkout path and primary color.
- Same-origin checkout iframe workflow with theme fallback.
- Variation validation and unsupported product-type fallback.
- Migration guard for the prior browser-side Express Buy Now snippet.
- WooCommerce admin settings page.
- HPOS compatibility declaration.
- Automated GitHub Actions PHP/JS/JSON validation and installable ZIP build.
